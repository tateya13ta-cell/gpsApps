# ชาวเจ้าสมุทร — Competitor Intelligence

เว็บแอปสำหรับสำรวจคู่แข่ง วิเคราะห์ตำแหน่งราคา และคำนวณราคาขายสำหรับ Modern Trade

## เปิดใช้งาน

- Live app: https://raw.githack.com/tateya13ta-cell/gpsApps/main/index.html
- GitHub Pages (เมื่อ Pages deployment เปิดใช้งาน): https://tateya13ta-cell.github.io/gpsApps/

## ความสามารถ

- เพิ่ม แก้ไข ค้นหา และกรองข้อมูลคู่แข่ง
- เปรียบเทียบราคาต่อกรัมและราคาเมื่อปรับเป็นน้ำหนักเดียวกัน
- คำนวณ Floor Price จากต้นทุน ของเสีย งบโปร Margin ห้าง VAT และกำไรเป้าหมาย
- จำลองราคา 3 กลยุทธ์: ประหยัด แข่งขันตรง และพรีเมียม
- วิเคราะห์คู่แข่งที่ต้องจับตา ช่องว่างตลาด และแผนตอบโต้
- ส่งออก JSON / CSV และนำเข้าข้อมูลสำรอง
- Responsive สำหรับคอมพิวเตอร์ แท็บเล็ต และมือถือ

ข้อมูลเวอร์ชันนี้บันทึกด้วย Local Storage ในเบราว์เซอร์ของแต่ละอุปกรณ์ จึงควรส่งออก JSON เพื่อสำรองข้อมูลเป็นระยะ
